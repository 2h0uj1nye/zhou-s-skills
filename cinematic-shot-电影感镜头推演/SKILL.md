# cinematic-shot · 电影感画面推演与镜头描述

> **合并说明**：本技能由两个上游技能收敛而来——`AI-Cinematic-Prompt-System`（以它的七模块决策链与正/负向钳制为主体）与 `cinematic-shot-description`（吸收其五段式输出骨架）。
> 后者的三个 references（examples / lighting-techniques / montage-guide）在源目录中并不存在，故未沿用；本包内 5 个 reference 均为合并时新建。

> **核心原则：** 摒弃关键词堆砌，先决策、后描述。输入一句创意种子 → 七模块推演 → 输出固定三件套（正向提示词 / 负向提示词 / 五段式画面描述）。任何决策都必须落地为提示词或描述中的具体约束，不留"只在脑子里"的废信息。

---

## 【输入】

**必填（缺一即先问）：** 主体 + 环境 + 核心动作/状态。一句话即可，例如：`23岁清冷女侠，竹林，月夜，看剑`。

**选填：** 输出语言、镜头数量（单镜头 / 蒙太奇）、机型或画幅偏好、目标平台（Midjourney / Stable Diffusion / DALL·E / 视频模型）。

**信息不足时先问这三项，不要替用户编主体：** ① 主体是谁（身份或年龄感）？② 在哪（空间类型 + 年代感）？③ 正在做什么（一个动词即可）？其余细节由七模块自行推演。

**用户只给一句抽象情绪时（如"孤独""希望"）：** 不要直接写"孤独的少女"。把情绪拆成三个可拍摄的物理落点——身体状态（姿态/手部/呼吸）、环境对应物（空椅/积水/未熄灭的烟）、光的行为（唯一光源偏置、暗部占画面比例），再把这三点当作创意种子进入七模块推演。

---

## 一、路径判断：先决定走哪条路

| 触发信号 | 路径 | 动作 |
|---|---|---|
| 单个画面、一张图、一个 prompt、"描述这个镜头" | **单镜头** | 七模块 → 输出一套三件套 |
| "一组镜头""分镜""多机位""蒙太奇""storyboard""这个场景的 5 个画面" | **蒙太奇序列** | 每个镜头独立走完七模块，但共享光源/色调/成像标准，逐镜输出后追加【蒙太奇节奏说明】 |

判断不清时默认单镜头，并在结尾补一句"需要多镜头版本可以告诉我"。蒙太奇规则见 [`references/montage.md`](references/montage.md)。

## 二、七模块推演入口

每模块必须产出**具体参数或物理细节**，并直接映射到正向或负向提示词的某一约束段。不可跳过，不可停留在抽象概念。

| # | 模块 | 一句话任务 | 必须落到提示词里的东西 |
|---|---|---|---|
| 1 | 人物谱系 | 定义主体的不可变基底 | 年龄感、体态、面容细节、服饰材质与磨损、身份符号、皮肤状态 |
| 2 | 视觉重力 | 划定**唯一**叙事焦点 | 微观焦点 + 至少两种聚焦手段 + 非焦点区域处理 |
| 3 | 叙事脉冲 | 浓缩场景的情绪核 | 一句情绪比喻（≤15 字）+ 一个可见物理叙事锚点及其对比关系 |
| 4 | 光学策略 | 镜头物理与空间构成 | 机身、焦段、光圈、快门、机位、取景排除项、景深、至少一项镜头瑕疵 |
| 5 | 色彩剧本 | 三色体系 | 主色 60%+ / 辅色 30% / 点缀色 <10% + 完整禁止色清单 |
| 6 | 照明档案 | 完整光影方案 | 光源逻辑、光质、光位光比、阴影决策、光影衰减与材质交互 |
| 7 | 氛围压强 | 整帧的不可量化特质 | 一段通感描述（嗅觉/触觉/听觉/时间感），与叙事脉冲呼应 |

各模块的必须涵盖项、判断标准与反例，见 [`references/modules.md`](references/modules.md)。
光影与材质术语库及描写范例，见 [`references/lighting.md`](references/lighting.md)。

## 三、五段式输出骨架（描述部分固定此结构）

每段必须以指定中文方括号标题开头，**段内为连续描述性文字，禁止使用列表项**。

```
【主体及环境】人物（身份/年龄感/穿着/姿态/表情/动作瞬间）+ 核心物件及其状态 + 环境场景与时代地域 + 环境细节（天气、湿度雾气尘埃、生活痕迹）+ 氛围暗示。

【构图与空间】景别（明确标注）+ 机位高度 + 构图法则 + 主体位置与视觉权重 + 前景层次 + 前中后景纵深结构 + 留白与密度。

【光影】依次覆盖七个维度：① 光源类型 ② 光线方向 ③ 明暗过渡 ④ 轮廓光 ⑤ 漫射光 ⑥ 丁达尔效应（不存在则明确写"无丁达尔效应"并给物理原因）⑦ 光影情绪。

【色调】主色调 + 色温估值 + 饱和度及分区差异 + 对比色关系 + 肤色还原 + 暗部色偏 + 高光色偏 + 整体调色风格。

【摄影与成像】固定标准文字，每次原样输出，不得改写。
```

【摄影与成像】固定标准文字（**原样照抄，不得修改、删减或添加**）：

> 电影画面质感，轻微柔焦光效，高光、人物皮肤边缘自然柔和扩散；适度画质损失，削弱强烈数码锐度，细腻胶片颗粒，自然动态模糊，原生镜头成像质感，富有真实生活气息。

若用户另行指定镜头参数（焦段/光圈/机型/介质），在固定文字**之后另起一行补充**，不得替代或修改固定文字。

## 【输出】固定三件套，顺序不变

**第一件 · 正向提示词**（英文，逗号分隔，按层叠加）：

```
masterpiece, best quality, cinematic shot on {机身}, {胶片或颗粒};
{人物谱系：年龄体态面容服饰身份符号皮肤状态};
focus on {微观焦点}, {聚焦手段}, {非焦点区域处理};
{情绪比喻}, narrative anchor: {物理锚点及对比关系};
{焦段} {光圈} {快门}, {机位}, exclude {取景排除项}, {景深}, {镜头瑕疵};
restricted palette: {主色} {占比}, {辅色} {占比}, {点缀色} {占比};
{光源逻辑}, {光质}, {光位光比}, {阴影决策}, {光影衰减与材质交互};
visible skin texture, realistic pores, peach fuzz in the light, subtle skin imperfections, fabric texture detail;
{通感描述}
```

**第二件 · 负向提示词**（英文，逗号分隔，权重用 `(词:1.x)`）：由正向决策**反向编译**，按第四节规则逐项列入，无例外、无遗漏。

**第三件 · 五段式画面描述**（中文，除非用户使用英文）：单镜头每段 3–6 句，【光影】段可加长到 6–10 句；多镜头各镜篇幅保持均衡。

## 四、负向钳制与反美颜（AI 最猜不到的规则，必须写）

AI 默认倾向生成"过度平滑、无瑕疵"的塑料脸，必须双向钳制。

**正向反美颜注入**（写进正向提示词）：
`visible skin texture, realistic pores, peach fuzz in the light, subtle skin imperfections, natural skin oiliness, fabric texture detail, material grain`

**负向反美颜高压钳制**（写进负向提示词）：
`(overly smooth:1.3), (plastic skin:1.3), (instagram filter:1.2), (liquefied effect:1.2), (airbrushed:1.2), perfect symmetry, (waxy skin:1.2), (porcelain skin:1.2), 3d render style, cgi look`

**反向编译规则（正向决策 → 负向词）：**

| 正向决策来源 | 编译为负向词 |
|---|---|
| 色彩剧本·禁止色清单 | 禁止色相**全部**逐一列入（具体到色相名，如 saturated yellow、warm orange） |
| 光学策略·取景排除项 | 排除的焦段、取景、景深效果全部列入 |
| 叙事脉冲·否定动态 | 被否定的动作与情绪全部列入 |
| 人物谱系·排除物件 | 排除的饰物、服装风格、妆造风格全部列入 |
| 反美颜系统 | 上述钳制词全部列入 |

同时**禁止**在正向提示词里出现 `perfect lens`、`sharp corners`、`flawless`、`perfect symmetry` 等完美化描述——真实感来自镜头瑕疵，不是来自完美。

完整词表、分题材补充词与各平台语法差异，见 [`references/negative-prompt.md`](references/negative-prompt.md)。

## 五、什么描述允许、什么必须改写（本技能的核心判断力）

| 类型 | 判定 | 处理 |
|---|---|---|
| 指向可视觉化微表情状态的描述 | ✅ 允许 | "眼神带有故事感"可以保留——它指向可被画出来的眼部微表情状态，而非抽象情绪标签 |
| 动词或比喻式情绪核，≤15 字 | ✅ 允许 | "被锈蚀与代码同时啃噬的守夜"可以，作为叙事脉冲 |
| 抽象情绪标签 | ❌ 必须改写 | "孤独""绝望""希望""忧郁"→ 换成物理状态：湿润眼眶、下眼睑轻微颤动、指节因用力泛白、嘴角下压的压痕、肩线塌陷 |
| 评价性/空泛语言 | ❌ 必须改写 | "画面很美""光影动人""高级感""很有氛围"→ 换成可还原的具体描写（光源位置、材质反馈、明暗占比） |
| 无物理来源的光 | ❌ 必须补 | 只写"氛围光"不行，须说明来源（窗外月光 / 霓虹招牌 / 手机屏幕反光），或标注为无源 bounce 并给强度 |
| 多焦点并列 | ❌ 必须收敛 | 视觉重力只允许**一个**焦点；其余区域写清虚化、压暗或切出画外 |

## 【步骤】

1. **解析输入**：抽出主体、环境、动作/状态、镜头数量、平台与语言；缺关键项先按【输入】提问。
2. **定路径**：单镜头，或蒙太奇序列。
3. **七模块推演**：逐模块填实，每模块产出具体参数与理由，不可跳过。
4. **组装正向提示词**：按 8 层顺序叠加，写入反美颜质感词与镜头瑕疵。
5. **反向编译负向提示词**：按第四节表格逐项列入，叠加反美颜钳制词。
6. **写五段式描述**：【光影】必须覆盖七个维度，【摄影与成像】原样照抄固定文字。
7. **蒙太奇校验**（如适用）：逐镜检查色调/光源/成像标准一致，标注时长，追加【蒙太奇节奏说明】。
8. **自检**：执行下方验证清单，不合格则回炉。

---

## 【坑点】

- **跳过模块**：任何模块停在抽象概念（如"高级感的光"）都会让结果退化成关键词堆砌。缺参数就是没做完。
- **负向词漏编译**：禁止色、排除焦段、否定动态必须逐项列入，漏一项画面就会自己长回来。
- **塑料脸**：不写反美颜钳制，AI 一定给磨皮网红脸；只写钳制却漏掉 `visible skin texture` 等正向质感词，同样会糊。
- **丁达尔滥用**：无雾、无烟、无缝隙的场景硬写丁达尔，画面会假。没有条件就明确写"无丁达尔效应"并给原因。
- **固定文字被改写**：【摄影与成像】是统一成像标准，多镜头之间必须完全一致，改动它会破坏序列连贯性。
- **多焦点**：视觉重力写了两个以上焦点，画面注意力会被撕碎。
- **蒙太奇断链**：前序镜头出现的环境元素（墙上光斑、桌上水杯）在后续镜头里凭空消失。
- **光影占比失衡**：只写灯位名，不写光怎么走、怎么衰减、撞到材质怎么反应，画面就还是平的。

## 安全与边界

- **真人肖像**：可描述虚构人物的气质、年龄段与装束；若用户提供真实人物照片或姓名，只做泛化的视觉特征转译（体型、服装、环境、光线），不生成用于冒充、伪造身份或误导性传播的真人肖像，也不做换脸式描述。
- **版权角色**：不逐字复刻仍在版权保护期内的具体角色形象或标志性造型；改写为"同类视觉特征 + 不同设定"的原创角色，或明确提示该用途的授权风险。
- **真实暴力/犯罪**：可做戏剧化虚构场景，但不输出可用于真实伤害的操作性细节（爆炸物制作、伤害手法步骤等），画面描述停留在视觉与情绪层面。
- **本技能不涉及任何凭据、密钥、账号或隐私数据的读写**；用户提供的素材仅用于本轮画面推演，不写入文件、不外传。
- 输出若与用户所在司法管辖区的合规要求冲突，拒绝该部分并说明原因。

## 【验证】自查清单（逐条过，不合格则回炉）

**结构**
- [ ] 五段是否齐全：【主体及环境】【构图与空间】【光影】【色调】【摄影与成像】
- [ ] 五段内是否**没有**使用列表项（必须是连续描述性文字；本清单本身不算输出内容）
- [ ] 【摄影与成像】固定标准文字是否原样、完整、未改写、未删减
- [ ] 单镜头每段 3–6 句、【光影】6–10 句？多镜头各段篇幅是否均衡？

**内容**
- [ ] 是否输出了**负向提示词**，且权重使用 `(词:1.x)` 格式？
- [ ] 负向词是否覆盖了：禁止色全部、排除焦段/取景全部、否定动态全部、反美颜钳制词全部？
- [ ] 正向提示词是否包含反美颜质感词（visible skin texture / realistic pores / peach fuzz）？
- [ ] 是否把抽象情绪改写成了可视觉化状态？（自查：输出里还有"孤独""很美""高级感"这类词吗？有就回炉）
- [ ] 视觉重力是否**只有一个**焦点，且写明了非焦点区域的处理方式？
- [ ] 【光影】七维度是否全部覆盖，丁达尔维度是否给出存在理由或"无丁达尔效应"的原因？
- [ ] 光学策略是否至少给出一项**镜头瑕疵**（焦外形态/暗角/色散/呼吸效应）？
- [ ] 三色比例是否明确（主色 60%+ / 辅色 30% / 点缀色 <10%）？
- [ ] 是否避免了 `perfect`、`flawless`、`perfect lens` 等完美化描述？

**蒙太奇（如适用）**
- [ ] 每个镜头是否独立使用完整五段式，并以 `---` 与镜头编号分隔？
- [ ] 色调、光源、成像标准是否跨镜头一致？
- [ ] 是否标注每镜建议时长，并追加【蒙太奇节奏说明】（组接逻辑、转场方式、情绪推进曲线）？
- [ ] 前序镜头的环境元素是否在后续镜头中保持存在且状态连贯？
