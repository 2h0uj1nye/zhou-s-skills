# 光影技术库

本文件服务于 [`../SKILL.md`](../SKILL.md) 第三节【光影】段与模块 6 照明档案。【光影】是本技能的重点刻画段落，**七个维度须全部覆盖，不可遗漏**；每个维度都要结合具体场景的物理条件描写，而非泛泛而谈。

---

## 一、七维度速查

| # | 维度 | 必须回答的问题 | 缺失时的后果 |
|---|---|---|---|
| 1 | 光源类型 | 有哪些光源？主/辅层级？有无反射光、环境 bounce？ | 光变得"没有来源"，AI 随机布光 |
| 2 | 光线方向 | 主光源相对主体/镜头的方位？多光源各自方位？对造型的影响？ | 体积感丢失，人物变扁平贴纸 |
| 3 | 明暗过渡 | 硬边还是软边？过渡区宽窄与位置？反差比？暗部是否保留细节？ | 要么死黑一片，要么全是灰 |
| 4 | 轮廓光 | 有无 rim light？方向、宽度、强度、色温偏移？ | 主体与背景粘连，抠不出来 |
| 5 | 漫射光 | 来源与强度？柔化贡献？填充阴影的程度？色温特征？ | 暗部生硬，缺乏真实环境感 |
| 6 | 丁达尔效应 | 有无可见光路？触发介质是什么？光束形态与走向？ | 滥用会假；该有没有会空 |
| 7 | 光影情绪 | 整体传达什么情绪？与叙事主题如何呼应？ | 光影与故事脱节 |

## 二、逐维度细则与范例

### 1. 光源类型
- **自然光**：日光、月光、天光（阴天漫射）
- **人造光**：钨丝灯（暖黄 3200K）、荧光灯（偏绿）、LED、烛火（跳动、色温极低）、霓虹（高饱和、单色性强）
- **混合光源**：室内钨丝 + 窗外天光的经典冷暖对冲
- 标注主光源与辅助光源的层级关系；反射光与环境 bounce 须说明来源与强度

> 范例：主光为窗外天光（无源，强度中等，色温 5600K），辅光为室内钨丝台灯（有源，暖黄 3000K，位于画面右侧画面外），右墙白色乳胶漆提供弱 bounce 提亮人物左颊暗部。

### 2. 光线方向
顺光 / 侧光 / 逆光 / 侧逆光 / 顶光 / 底光。多光源时分别标注。
- 侧光与侧逆光 → 塑造体积感与明暗交界线
- 顺光 → 扁平化，适合喜剧、日常、广告质感
- 逆光 → 剪影化、轮廓分离，适合神秘与牺牲感
- 顶光 → 眼窝阴影加深，压迫、审判感
- 底光 → 反常、恐怖、火光摇曳时的真实物理

经典光位名可直接使用：**伦勃朗光**（面部三角光斑）、**蝴蝶光**（鼻下蝶形阴影）、**分割光**（正中分界线）、**环形光**。

### 3. 明暗过渡
- **硬边过渡**：清晰明暗分界，来自小面积硬光源或直射光
- **软边过渡**：渐变柔和，来自大面积光源、柔光箱或漫射介质
- 写明过渡区域的**宽窄与位置**（如"明暗交界线落在颧骨至下颌，宽约一指"）
- 反差比：高反差（8:1 以上）/ 中间调（4:1 左右）/ 低反差（2:1）
- 暗部可读性：死黑 or 保留细节。**保留细节须写明保留比例**（如"保留 3% 环境反光"）

### 4. 轮廓光
- 是否存在 rim light / edge light
- 光源方向与主体边缘的关系（后侧 45°、正后方、侧后方低位）
- 宽度（细如发丝 / 约两指宽）、强度、色温偏移
- 对主体从背景中分离的贡献——暗背景上的亮轮廓是最经济的分离手段

> 范例：品红霓虹招牌构成的左逆光轮廓光，只在人物肩线与发丝边缘形成约一指宽的品红亮边，与深青蓝主调形成冷暖撕裂，把人物从暗巷背景中剥离出来。

### 5. 漫射光
- 来源：天空漫射、墙面 bounce、雾气或雨幕散射
- 强度与对整体画面柔化的贡献
- 对阴影的填充程度——阴影被环境光提亮多少
- 色温特征：天光漫射偏冷蓝、白墙 bounce 偏中性、暖色物体 bounce 偏暖

### 6. 丁达尔效应
- 触发条件**必须存在**：雾气、烟尘、水汽、窗帘缝隙、树冠漏光、室内灰尘
- 光束形态：平行光束、散射光锥、体积光的浓度梯度
- 光束在空间中的走向，及其与构图的关系（用光束作引导线是常见手法）
- **若场景中不存在触发条件，明确写"无丁达尔效应"并解释原因**（如"室内无扬尘、光源为漫射天光，无可见光路"）。滥用是本技能最常见的失真来源。

### 7. 光影情绪
- 整体情绪：温暖 / 冷峻 / 神秘 / 压抑 / 空灵 / 日常感
- 与叙事主题及模块 3 叙事脉冲的呼应关系；矛盾时必须改光影，不改叙事脉冲

## 三、光影衰减与材质交互对照表

模块 6.5 的核心。写作公式：**光线从哪来 → 经过什么介质 → 怎么衰减 → 撞到什么材质 → 产生什么反馈**。

| 材质 | 光的反馈 | 建议写入正向提示词的英文词 |
|---|---|---|
| 金属（抛光） | 镜面高光、清晰反射、边缘高亮 | `specular highlight, polished metal reflection` |
| 金属（哑光/氧化） | 漫反射为主的暗光泽，高光被摊开 | `matte metal, diffused sheen, oxidized surface` |
| 皮肤（微油/微汗） | 柔和反射 + 可见纹理与毛孔，额鼻处出现柔和光斑 | `visible skin texture, realistic pores, subtle skin oiliness` |
| 皮肤（干燥/风尘） | 高光弱，细纹与脱屑可见 | `dry skin texture, fine lines, dust on skin` |
| 皮肤（细绒毛） | 逆光下细绒毛透光发亮 | `peach fuzz in the light, backlit fuzz` |
| 亚麻/棉布 | 漫反射，褶皱受光面与背光面分明 | `fabric texture detail, linen weave, folding shadows` |
| 皮革 | 半光泽，磨损处哑光，边缘起毛 | `worn leather, semi-gloss patina` |
| 液体/湿润表面 | 高光斑点 + 折射 + 倒影破碎 | `wet surface, specular highlights, refraction, rain droplets` |
| 玻璃 | 透射 + 反射叠加，边缘色散 | `glass refraction, edge dispersion` |
| 雾/烟 | 体积散射，光路可见，远处对比度下降 | `volumetric fog, atmospheric haze, light scattering` |

> 完整范例（结合多材质）：侧逆光穿过薄纱窗帘产生衍射模糊，在木地板上形成边缘柔和的斜长光斑；剑身金属表面形成锐利镜面高光；人物脸颊出现明暗交界线，阴影区保留 3% 环境反光仍可辨五官；皮肤在微凉夜风中可见真实纹理与细微绒毛，在月光下呈冷粉色偏移。
