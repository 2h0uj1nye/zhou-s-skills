# 七模块推演细则

本文件是 [`../SKILL.md`](../SKILL.md) 第二节的展开。每个模块的产出必须满足两个条件：**① 有具体参数或物理细节，不可停留在抽象概念；② 直接映射到正向或负向提示词的某个约束段。**

推演顺序不可打乱：人物谱系定基底 → 视觉重力定焦点 → 叙事脉冲定情绪核 → 光学策略定镜头 → 色彩剧本定色 → 照明档案定光 → 氛围压强定空气。后模块可以修正前模块（例如照明档案发现光源与色彩剧本的色温冲突），但不可跳过。

---

## 模块 1 · 人物谱系

定义主体人物的**不可变基底**——出场后不随镜头变化的部分。

**必须涵盖：**
- 年龄感与体态（消瘦 / 壮硕 / 匀称，需精确到筋骨状态，如"消瘦但筋骨紧实"）
- 面容特征（颧骨、下颌线、疤痕、义体置换等可视觉化细节）
- 服饰材质与剪裁（面料磨损程度、内衬状态、金属配件位置）
- 身份符号（牌照、纹身、徽记、工具等叙事性物件）
- 皮肤状态（微油 / 微汗 / 干燥 / 风尘）——为后续光影与材质交互提供物理依据

**关键约束：**
- 只描述**承载情绪的外壳**，不写情绪本身。
- "眼神带有故事感"这类描述**允许**——它指向一种可被视觉化的微表情状态，而不是抽象情绪标签。
- 每个特征都要能画出来。写"气质忧郁"无效，写"眼窝深陷、下眼睑有青黑、嘴角下压"有效。

> 示例：34 岁退役义体侦探，消瘦但筋骨紧实，左眼为义眼置换件发出淡青白微光，高颧骨硬朗下颌线，左眉骨贯穿旧疤，黑色合成皮长风衣内衬磨损露出金属纤维，右手半指战术手套，左前臂哑光黑机械义肢关节处可见油污，腰间褪色金属侦探牌照，颈侧条形码纹身。

## 模块 2 · 视觉重力

划定画面的**唯一叙事焦点**，并强制绑定实现该焦点的技术手段。没有视觉重力的画面，AI 会把注意力平均撒满全图。

**必须涵盖：**
- 焦点是什么，具体到微观细节（如"剑刃上的一道缺口""义眼微光在弹壳上的反射"）
- 用何种技术手段实现聚焦，**以下至少选两种**：
  - 浅景深锁定（指定 T 值或 f 值）
  - 局部打亮（光源直射焦点区域）
  - 视线引导（人物目光方向指向焦点）
  - 构图权重（焦点位于黄金分割点或视觉中心）
  - 色彩对比（焦点区域使用画面中唯一的高对比色）
- 非焦点区域如何处理：虚化、压暗，或直接切出画外

**关键约束：**
- 焦点只能是**一个**，不可多焦点并列。
- 非焦点区域的交代不是可选项——它决定了焦点是否真的被"突出"。

> 示例：焦点是义眼淡青白光与其在指尖旧弹壳上的微观反射。实现手段——浅景深 T1.8 锁死在"义眼—弹壳反射"这一微观细节上；面部其余部分进入焦外；霓虹环境光被压成散景圆点；义眼自发光成为局部高亮，天然吸走全部视觉权重。

## 模块 3 · 叙事脉冲

浓缩整个场景的情绪核，是"决定性瞬间"与"导演意图"的统一表达。

**必须涵盖：**
- 一句核心情绪定义（动词或比喻句，**不超过 15 字**）
- 一个叙事锚点——具体的物理物件，用来承载抽象情绪

**关键约束：**
- 情绪定义**只用一个动词或比喻句**，不展开描述。展开就变成文案，不是提示词。
- 叙事锚点必须是**可见的物理细节**，不可写成抽象状态。
- 锚点应与画面其他元素形成对比关系：色温对比、质感对比、新旧对比、有机 vs 机械。

> 示例：情绪核——"被锈蚀与代码同时啃噬的守夜"。叙事锚点——旧弹壳的黄铜色泽与义眼的青白冷光形成"有机 vs 机械"的对比。

## 模块 4 · 光学策略

镜头物理属性与空间构成决策，**强制输出真实相机参数与镜头瑕疵**。

### 4.1 基础参数
- 相机机身（Canon EOS R5 / Arri Alexa 65 / Sony Venice 等）
- 焦段（24 / 35 / 50 / 85 / 135mm），须说明选择理由（85mm 压缩空间适合人物特写，24mm 强调环境与纵深）
- 机位（平视 / 微仰 / 微俯 / 仰拍 / 俯拍 / 过肩）
- 取景边界——**排除什么比纳入什么更重要**，须明确列出排除项

### 4.2 光学物理（打破 AI 塑料感的关键）
- 光圈值（如 f/1.4 制造浅景深，须说明景深效果）
- 快门速度（如 1/60s 带来轻微运动模糊，须说明模糊方向与程度）
- 镜头光学缺陷，**至少选一项**：
  - 焦外光斑形态（非正圆：橄榄形、猫眼变形）
  - 边缘暗角（轻微 / 中等，须标注强度）
  - 高光区域色散（紫边 / 绿边，须标注位置）
  - 镜头呼吸效应（对焦切换时的焦距微变）

**关键约束：**
- 光学缺陷是"真实感"的来源，不是错误——必须写进正向提示词。
- 不可使用 `perfect lens`、`sharp corners` 等完美化描述。

> 示例：Canon EOS R5，85mm f/1.4，平视机位；剔除天空，保留竹林纵深；浅景深锁定焦点；画面带轻微暗角，焦外竹叶光斑呈橄榄形，高光边缘有极轻微紫边。

## 模块 5 · 色彩剧本

严格限定三色体系，并指定各色的情绪功能与面积分配。

### 5.1 三色体系（强制比例分配）
- **主色**：占 60% 以上面积，决定基调
- **辅色**：约占 30%，与主色形成对话或对抗
- **点缀色**：10% 以下，制造视觉刺痛点
- 每色须标注情绪功能（"冷峻""对抗""刺痛"等）

### 5.2 禁止色清单
- 列出所有不允许出现在画面中的色相
- 此清单**直接进入负向提示词**，不另起逻辑

**关键约束：**
- 三色之外的所有色相都应进入禁止色清单。
- 禁止色要具体到色相名（`saturated yellow`、`warm orange`），不可笼统写"其他颜色"。
- 人像题材务必同时给出**肤色还原**方向（偏暖橘 / 偏中性 / 偏冷粉）与暗部色偏，否则 AI 会自行填入默认肤色。

> 示例：主色——深青蓝（60%+，冷峻基调）；辅色——品红霓虹（30%，冷暖对抗）；点缀色——义眼淡青白光（<10%，视觉刺痛点）。禁止色：饱和黄、暖橙、纯绿、明亮红、日光白。肤色偏冷粉，暗部偏青。

## 模块 6 · 照明档案

完整光影方案，从"布光位置"升级为"**光影衰减逻辑与材质交互**"。

**必须涵盖五个维度：**

### 6.1 光源逻辑
- 有源光源（月光、烛火、霓虹招牌、窗外光等，须说明物理来源）
- 无源光（环境天光、bounce 反射，须标注强度）
- 主光源与辅助光源的层级关系

### 6.2 光质
- 硬光 / 软光 / 体积光 / 漫反射
- 须说明光质选择的物理原因（"霓虹灯管为硬光源""雨幕散射形成漫射"）

### 6.3 光位与光比
- 主光源方向（顺光 / 侧光 / 逆光 / 侧逆光 / 顶光 / 底光；可用经典光位名，如伦勃朗光、蝴蝶光）
- 光比（如 2:1 低调、8:1 高反差）
- 高调 / 低调 / 中间调

### 6.4 阴影决策
- 暗部状态（深黑死黑 / 通透暗部保留细节 / 完全无影）
- 阴影边缘（硬边 / 软边过渡）
- 阴影区环境反光比例（如"保留 3% 环境反光"）

### 6.5 光影衰减与材质交互
- 光线在空间中的物理衰减路径（如"侧逆光穿过薄纱窗帘产生衍射模糊，在木地板上形成边缘柔和的斜长光斑"）
- 材质对光的反馈：金属 → 镜面高光；皮肤（微油/微汗）→ 柔和反射 + 可见纹理；亚麻布料 → 漫反射且褶皱受光/背光面分明；液体或湿润表面 → 高光斑点 + 折射

**关键约束：**
- 不可只写灯位名，必须描述光在空间中"怎么走、怎么衰减、碰到什么材质怎么反应"。
- 皮肤材质交互须写进正向提示词（`visible skin texture` / `realistic pores` / `peach fuzz`）。

> 示例：冷调月光主光，右后方 45° 伦勃朗光位（有源：月亮）。光线穿过雨幕产生体积散射，到达人物时已柔化为半硬光。剑身金属表面形成锐利镜面高光；脸颊形成明暗交界线，阴影区保留 3% 环境反光可辨五官；皮肤在微凉夜风中可见真实纹理与细微绒毛，月光下呈冷粉色偏移。

各维度术语与更多描写范例见 [`lighting.md`](lighting.md)。

## 模块 7 · 氛围压强

整帧的不可量化特质，以**通感语言**定义。它决定了画面"空气的质感"，是 AI 最难从关键词推断、也最容易让成图脱离塑料感的一层。

**必须涵盖：**
- 一段通感描述，融合视觉以外的感官：嗅觉、触觉、听觉、时间感
- 须与叙事脉冲呼应，不可矛盾

**关键约束：**
- 不可用"很好看""很有氛围"等评价性语言。
- 须用具体的感官意象，让模型理解空气的质地（湿度、颗粒、温度、声音密度）。

> 示例：空气里混着臭氧、铁锈与湿沥青的气味，雨声像加密数据流一样细密不歇，时间在扳机保险与一段遗忘的密码之间凝成了固体。

## 模块间冲突的裁决顺序

1. **物理真实性优先于美观**：光源方向与阴影方向冲突时，改阴影，不改光源。
2. **视觉重力优先于色彩剧本**：焦点色的对比需求可以突破"三色之外禁入"的规则，此时把该色计入点缀色，而不是放弃焦点。
3. **叙事脉冲优先于氛围压强**：两者矛盾时改氛围压强。
4. **用户明确指定的参数优先于一切推演**：用户给了机型、焦段或色号，直接采用，推演在其约束内进行。
