# 蒙太奇序列规则

本文件展开 [`../SKILL.md`](../SKILL.md) 第一节的"蒙太奇序列"路径。当用户要求生成多镜头蒙太奇（一组分镜、一个场景的多个机位）时适用。

---

## 一、结构统一

- 每个镜头**独立使用完整的五段式结构**输出，不做任何段落的省略或合并。
- 镜头之间以分隔线（`---`）和镜头编号标注分隔。
- 每个镜头标题格式：`## 镜头 NN — [镜头标识，如"全景·街道"]`
- 单镜头描述篇幅保持 3–6 句/段，【光影】6–10 句；**各镜篇幅保持均衡**，避免某镜明显膨胀。

格式模板：

```
## 镜头 01 — [镜头标识]

【主体及环境】
...

【构图与空间】
...

【光影】
...

【色调】
...

【摄影与成像】
电影画面质感，轻微柔焦光效，高光、人物皮肤边缘自然柔和扩散；适度画质损失，削弱强烈数码锐度，细腻胶片颗粒，自然动态模糊，原生镜头成像质感，富有真实生活气息。

---

## 镜头 02 — [镜头标识]
...
```

【摄影与成像】的固定标准文字在所有镜头中**必须完全相同**。

---

## 二、视觉连贯性五保

同场景多镜头最容易崩在"看起来不像同一个地方"。以下五条逐镜检查：

1. **色调一致**：同一场景的多个镜头须保持统一的色温和调色风格，仅允许因机位不同产生的细微变化。
2. **光源一致**：同一场景的光源设定（方向、类型、强度）在所有镜头中保持一致；不同机位**只改变光线与主体的相对关系**，不改变光的物理存在。
3. **成像标准一致**：所有镜头的【摄影与成像】段落使用完全相同的固定标准文字，一字不改。
4. **环境细节呼应**：前序镜头中出现的环境元素（墙上的光斑、桌上的水杯、地面的积水）在后续镜头中须**保持存在且状态连贯**（位置不变，不凭空消失，不无故增减）。
5. **时间连贯**：同一场景的镜头须处于同一时间段，光影的细微变化仅源于机位差异而非时间推移——除非用户明确要求"时间流逝蒙太奇"，此时须显式说明时间跨度。

> 断链是蒙太奇最常见的失败：镜头 01 里桌上有一只冒热气的杯子，镜头 03 里杯子没了。校验时逐条比对前序镜头的环境元素清单。

---

## 三、景别与机位的节奏设计

镜头之间要有**视觉差异**，否则蒙太奇无意义。建议组合：

| 位置 | 景别 | 作用 |
|---|---|---|
| 建立镜 | 远景 / 全景 | 交代空间、时代、环境 |
| 关系镜 | 中景 | 交代人物与环境/他人的关系 |
| 情绪镜 | 近景 | 表情与姿态 |
| 强调镜 | 特写 / 大特写 | 落到视觉重力的微观焦点上 |
| 收束镜 | 全景 / 空镜 | 情绪余韵、抽离 |

避免连续两镜使用同一景别与同一机位高度；避免整组镜头全是特写（观众失去空间感），也避免全是全景（没有情绪入口）。

---

## 四、蒙太奇节奏

- **标注每镜的建议时长**（如 3s / 5s / 8s），时长应与镜头信息量匹配：特写短（2–4s），全景长（5–8s）。
- 在全部镜头输出后，附加一段【蒙太奇节奏说明】，包含：
  - **组接逻辑**：镜头为什么按这个顺序排列，情绪如何递进
  - **转场方式**：硬切 / 叠化 / 匹配剪辑（match cut）/ 跳切 / 淡入淡出，逐处标注
  - **情绪推进曲线**：用一句线性的描述刻画张力走向（如"从静到动、由外及内，在第 3 镜收束于静止"）
  - **建议配乐或声音层**（可选）：环境声与音乐的进出点

---

## 五、转场方式速查

| 转场 | 适用场景 | 视觉提示词写法 |
|---|---|---|
| 硬切 | 冲击、并列、对比 | 无过渡，直接两镜相接 |
| 叠化 | 时间流逝、回忆、柔和过渡 | `dissolve transition, overlapping exposure` |
| 匹配剪辑 | 形状/动作/构图高度相似的两镜 | 两镜的构图描述需刻意呼应（如同为圆形物体） |
| 跳切 | 焦躁、省略、时间压缩 | 同机位同景别，主体位置突变 |
| 淡入淡出 | 段落起止、情绪封闭 | `fade in from black` / `fade to black` |

---

## 六、蒙太奇自检清单

- [ ] 每镜是否独立完整五段式，且以 `---` + `镜头 NN` 分隔？
- [ ] 景别与机位是否逐镜有变化，且不出现连续重复？
- [ ] 色调、光源、成像标准是否跨镜一致？
- [ ] 前序镜头的环境元素是否在后续镜头中保持存在且状态连贯？
- [ ] 是否给每镜标注了建议时长？
- [ ] 是否在结尾追加了【蒙太奇节奏说明】（组接逻辑 + 转场方式 + 情绪推进曲线）？
- [ ] 各镜篇幅是否均衡？
- [ ] 指定时间流逝时，是否显式说明了时间跨度？
