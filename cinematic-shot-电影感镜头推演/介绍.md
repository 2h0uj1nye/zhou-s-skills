# 电影感镜头推演（cinematic-shot）

> 一句话：给你一句画面想法（比如"23 岁清冷女侠，竹林，月夜，看剑"），它先想清楚怎么拍，再产出一套能直接丢给画图/视频 AI 的提示词，外加一段读起来像分镜的中文画面描述。

| 项目 | 内容 |
|---|---|
| 宿主 | DSH（Ubuntu 24.04 实测可用；纯文字技能，不调用任何绘图或视频接口） |
| 外部依赖 | 零依赖 |
| 产出 | 固定三件套：英文正向提示词 / 英文负向提示词 / 中文五段式画面描述（多镜头时逐镜输出 + 节奏说明） |
| 入选理由 | 不是套模板堆关键词，而是"先决策、后描述"的七模块推演链，带可逐条打勾的自查清单，反"塑料脸"那段是真差异化 |

## 它解决什么问题

用 AI 画图的人大多卡在同一件事：知道想要"电影感"，写出来的提示词却是一堆形容词，出来的图千人一面——过度磨皮的脸、站不住的塑料光、构图永远居中。
问题不在词不够多，而在**没做决定**：光从哪来、焦点在哪、什么颜色不许出现，这些没定下来，AI 就自己替你想了，而且是往最俗的方向想。

## 什么时候该用它

- "帮我写一段 Midjourney 提示词：雨夜的赛博朋克侦探。"
- "把这个场景做成分镜文案，要五个画面。"
- "我小说里这段场景想要电影感的画面描述。"
- "想要一组风格统一的图，光影和色调别乱跑。"

## 什么时候别用它

- 你只要纯文字叙事或剧本对白——它输出画面描述和提示词，不写故事。
- 你要给真实剧组用的技术灯光参数表（灯具型号、色温、照度）——不是这个用途。
- 你要复刻真实人物或仍在版权期的具体角色形象——它明确拒绝真人肖像伪造和逐字复刻版权造型，只做泛化的视觉特征转译。

## 怎么开口

- "竹林，月夜，女侠看剑，写一套绘图提示词。"
- "一个义体侦探在雨夜捡到弹壳，要电影感的画面，给单个镜头。"
- "把'孤独'做成一个画面，要能直接拿去画图。"

## 输入 / 输出

**它会向你要三样（缺一样就反过来问你，不替你编）：** 主体是谁、在哪（空间 + 年代感）、正在做什么（一个动词就够）。还可选填输出语言、单镜头还是多镜头、机型或画幅偏好、目标平台（Midjourney / Stable Diffusion / DALL·E / 视频模型）。**如果只给一个抽象情绪词**（"孤独""希望"），它先把情绪拆成三个能拍的物理落点——身体状态、环境里的对应物、光的行为——再往下推演。

**最后给你三件套，顺序固定：**
1. **正向提示词**（英文、逗号分隔、按 8 层叠加：成像质感 → 人物 → 焦点 → 叙事锚点 → 镜头参数 → 色彩比例 → 光 → 皮肤质感 → 通感）。
2. **负向提示词**（英文，权重写成 `(词:1.3)` 这种形式，由正向决策**逐项反向编译**得来，不是随手抄的万能词表）。
3. **中文五段式画面描述**：`【主体及环境】【构图与空间】【光影】【色调】【摄影与成像】`，段内必须连续成文、不许用列表。

## 依赖与前提

无。不需要装软件、不需要联网、不需要 API key——它只产文字，拿到提示词之后要画图是另一回事。

## 注意事项与已知限制

- **`【摄影与成像】`那段固定文字必须原样照抄**，不改写不增删；多镜头之间也必须完全一致，改了会破坏整组图的连贯性。
- **五段里禁止用列表**，只能写成连续描述性文字；**篇幅有硬下限**：单镜头每段 3-6 句、`【光影】`段 6-10 句，一次完整输出通常上百行，不适合"随便来一句"。
- **光柱（丁达尔效应）不许硬套**：没有雾、烟、缝隙的场景必须明写"无丁达尔效应"并给原因，否则画面会假。
- 安全边界：真人照片或姓名只做泛化视觉转译、不做换脸；不逐字复刻版权角色；不输出可用于真实伤害的操作性细节。它本身也不画图、不出视频，不校验平台端最终效果。
