# 全库审计细则

与 diff 审查同一套规则，但扫描整棵树而不是一个 diff。**按删减量从大到小排名。**

## 狩猎清单

- 标准库或平台已经提供的依赖
- 只有一个实现的接口、只有一个产品的工厂
- 只做转发的包装层
- 只导出一个东西的文件
- 没人设的开关与配置
- 手写的、标准库已有的功能
- 死代码与永远不会走到的分支

跳过 `node_modules`、`.git`、构建产物、vendored 第三方代码。

## 输出

一行一条，按删减量降序：`<tag> <该删什么>. <替代>. [路径]`
结尾：`net: -<N> lines, -<M> deps possible.`
无可删：`Lean already. Ship.`

## 边界

只覆盖过度设计与复杂度。正确性、安全、性能明确不在范围内，指路常规审查。
只列发现，不改动任何文件。一次性报告。
