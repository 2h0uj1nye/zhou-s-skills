## 2. 归类规则

- 一篇笔记**只归入一个最核心专题**（按主题优先，不按数量多寡）
- FAQ 文件按类别归入 02（思维）/ 08（软件）/ 06（编程）对应专题
- 案例笔记按**失败场景**归入对应工具 / 主题专题
- 专题文件格式：`NN-专题名.md` = 专题概述 + 笔记清单表（笔记 | 模块 | 核心内容）+ 学习路径 + 相关专题交叉引用
- 无法自动匹配 → 提示用户选择专题，或暂存 `归档\待分类\`

## 4. 归类流程

1. 蒸馏完成，笔记先写入工作位置
2. 检查标题与标签，匹配上面的关键词表
3. 移动到对应专题文件夹
4. 在 `NN-专题名.md` 的笔记清单表**追加一行**，并把该专题笔记数量 +1
5. 更新 `00-专题分类总览.md` 的专题地图（仅在新增专题时）
6. 播报：`新笔记《XXX》已归入 0X-XX 专题`

## 5. 脚本辅助

`scripts/classify_notes.py` 按本表的关键词给出归类建议，**默认 dry-run**，只打印计划不改文件：

```powershell
# 预演（推荐先跑）
python3 scripts\classify_notes.py --root "D:\AI云文档\AI知识库\AI学习知识库" --dry-run

# 确认后实际移动
python3 scripts\classify_notes.py --root "D:\AI云文档\AI知识库\AI学习知识库" --apply
```

脚本只处理根目录下的 `.md`，跳过 `专题\`、`meta\`、`归档\` 与总览类文件；未命中的文件会列出来供人工处理。
分类结果仍需人工或流程复核，不要盲目信任自动结果。

## 6. 分层存储（化杂为整四原则）

1. **物理隔离（分库）**：按专题文件夹分类，检索时只查对应库
2. **打标签（元数据）**：笔记加 frontmatter 标签（tags / topic / version / status）
3. **分层存储**：FAQ 层（根目录）→ 专题层（文件夹）→ 归档层（`归档\`）
4. **定期断舍离**：删除过期内容或标记"已过期"

整理时非核心内容（小说、哲学原文、电影观后感、一次性踩坑）移入 `归档\`，**移入不删除**，便于恢复。
