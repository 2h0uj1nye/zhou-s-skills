# 斯多葛控制二分法

**定位**：当焦虑来自"我控制不了的事"时，用来把处境切成**可控 / 不可控**两堆，把精力从不可控项撤回可控项。

## 触发信号

- "我很焦虑，一直想这件事"
- "万一……怎么办"（反复预演别人会怎么做）
- "我改变不了他/这个环境，但我放不下"
- 情绪被外部评价、结果、他人态度牵着走

## 不该用它

- **临床水平的焦虑/抑郁**（持续两周以上、影响睡眠与功能）→ 建议专业支持，不做模型推演。
- **用户只想被听见**：先共情，不要立刻上框架。
- **不可控项是他人侵害或结构性不公**（家暴、剥削、歧视）→ 先谈改变处境与求助，**绝不能用"接受"封口**。
- **需要情感表达与宣泄时**：此时分类会显得冷漠。
- 用户已经知道该怎么做、只是执行不了 → 这是执行问题，不是控制判断问题。

## 核心判断

1. 有些事在我们控制之内（判断、意图、行动），有些不在（他人、结果、天气、过去）。
2. 痛苦主要来自**对不可控项的判断**，而不是事件本身。
3. "接受"不等于"认可"，也不等于"不作为"——它的对象是**已经发生的事实**，不是不公的处境。

## 操作步骤

1. **列清单**：把让用户焦虑的事逐条写出来（写下来比在脑子里转有效）。
2. **逐条分类**：可控 / 部分可控 / 不可控。部分可控的要**再切一刀**，找出其中真正属于自己的那一小块。
3. **处理不可控**：明确说出"这一条不由我决定"，并写一句"我能做的是……"（把注意力锚回行动）。
4. **处理可控**：给出下一步的具体动作与时间点，越具体越好。
5. **检查判断本身**：对每个念头问一句"这是事实，还是我的解读？"（印象的同意）——多数焦虑来自同意的解读而非事实。
6. **预演（可选）**：写下最坏情形与应对方案，把恐惧变成准备。
7. **复查误判**：如果某条被判成"不可控"但其实可控，那是把责任推给了命运——重点检查这一类。

## 输出模板

```
焦虑清单：
- 事项 A → 可控 / 部分可控（我的那一块是……）/ 不可控
不可控项：能做的动作是……
可控项：下一步动作 + 时间点
我同意的解读：…… 事实是：……
需要复查的误判：……
```

## 判断标准

- 做对：焦虑下降、注意力回到具体行动、能说出"这不是我能决定的"而不带怨气。
- 做错：仍然反复反刍、精力分散、行动停滞。

## 误用模式

- **当成忍耐术**：教用户忍受不该忍受的处境（最重要的红线）。
- **当成逃避**：把"不可控"当免责标签，实际可控的事也划走。
- **当成压抑情绪**：斯多葛不要求没有情绪，只要求不被情绪牵着做决定。
- **替代心理治疗**：对临床问题给出哲学建议，会延误求助。
- **用它否定诉求**：把用户对不公的愤怒解释成"你该调整心态"。

## 边界与安全

- 涉及自伤/自杀念头、暴力处境、严重抑郁时，**立即停止模型化**，给支持性回应并建议专业帮助（心理热线/医疗机构）。
- 个人情绪内容属高敏隐私：只处理用户主动给出的部分，不外发、不落盘、不转述。
- 不诊断、不评价用户"心理素质"。

## 切换到其他模型

- 问题的主语变成"这是我自己选的，但不知道值不值得" → `eternal-recurrence.md`。
- 焦虑源于信息过载与失控的信息流 → `info-ecology.md`。
- 焦虑源于职业转型的不确定 → `cross-domain-transition.md`（先判断该不该走）。
- 涉及"该管多严"的组织问题 → `semi-control.md`。
