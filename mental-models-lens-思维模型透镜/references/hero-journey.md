# 英雄之旅（叙事结构）

**定位**：写故事、做品牌叙事、做演讲时，用来**组织一段有张力、能让人代入的叙事**。它是叙事工具，**不是人生决策工具**。

## 触发信号

- "帮我写一个品牌故事/演讲稿/产品发布文案"
- "这个故事没有张力，读起来平"
- "用户案例怎么讲才打动人"
- "设计一条个人品牌故事线"

## 不该用它

- 非叙事内容（技术文档、数据报告、说明书）。
- 用户在做**真实人生抉择**——那是 `eternal-recurrence.md` / `stoic-control.md` 的领域（见"误用模式"第 1 条）。
- 已经过度使用、读者对套路免疫的场合。
- 只需要信息图/分镜视觉模板时：叙事弧线的可视化已有现成模板（如 baoyu-infographic 的 story-mountain），**不要用本模型重画一遍**。

## 核心判断

1. 跨文化神话共享一套深层结构（出发—启蒙—归来），它对应人**分离—转变—回归**的心理过程。
2. 结构是骨架不是公式：照搬会导致套路感，必须换成具体、独特、可信的细节。
3. 品牌叙事里**英雄是用户（或读者），不是公司**——把公司写成英雄是最常见的失败。

## 操作步骤

**坎贝尔 17 阶段（权威结构，三段式）**

- 出发：① 冒险的召唤　② 拒绝召唤　③ 超自然助力　④ 跨越第一道门槛　⑤ 鲸鱼之腹（彻底进入未知）
- 启蒙：⑥ 试炼之路　⑦ 与女神相会　⑧ 诱惑/分心之物　⑨ 与父亲和解（与权威/旧自我的和解）　⑩ 神化　⑪ **终极恩赐**（获得的宝物/真相/能力）
- 归来：⑫ 拒绝回归　⑬ 魔法飞行（仓促/艰难的撤离）　⑭ 外界救援　⑮ 跨越归来门槛　⑯ 两个世界的主宰　⑰ 自由生活

> 说明：原 `campbell-hero-journey` 技能的阶段表有误——漏掉"终极恩赐"（The Ultimate Boon），且第 34 行的 "rewards" 未翻译、与"奖赏"重复。上表为修正后的完整结构。

**写作实用的 12 阶段缩编**（剧本/文案常用）：平凡世界 → 冒险的召唤 → 拒绝召唤 → 遇见导师 → 跨越第一道门槛 → 试炼、盟友、敌人 → 接近最深的洞穴 → 磨难 → 奖赏 → 回归之路 → 复活 → 带着灵药归来。

**落地流程**
1. 确定**谁是英雄**（读者/用户/主角），确定他原本的"平凡世界"。
2. 写清**召唤**与**代价**：他要放弃什么？损失必须具体。
3. 设计**磨难**：最痛的一刻，主角被迫面对自己的缺陷。
4. 给**终极恩赐**：他带回了什么（能力、认知、关系、工具）——这是故事的主题句。
5. 写**归来**：他回到原世界后，什么被改变了？没有归来 = 故事没闭环。
6. 删套路：凡是换成任意品牌都成立的句子，删掉重写。

## 输出模板

```
英雄（谁）：…… 平凡世界：……
召唤与拒绝：…… 跨越门槛的代价：……
试炼与磨难（最痛的一刻）：……
终极恩赐（主题句）：……
归来与改变：……
具体细节（防套路）：……
```

## 判断标准

- 做对：读者能代入、有情绪起伏、能复述主题句。
- 做错：平淡无感，或读者一眼看出是模板。

## 误用模式

- **把叙事当人生分析**（最重要）：用"我现在在第二幕"解释自己的真实处境，是一种自我安慰的叙事自欺。真实抉择请走 `eternal-recurrence.md`。
- **公司当英雄**：品牌故事里主角必须是用户，公司是导师/助力。
- **忽略终极恩赐**：只有磨难没有收获，读者感到被消耗。
- **唯结构论**：以为套上 17 阶段就有张力，忽略细节与可信度。
- **把过时术语照搬**："作为诱惑者的女人"是历史表述；现代用法应还原为"让人偏离使命的诱惑/分心之物"，并注意性别化表述带来的冒犯。

## 边界与安全

- 不把他人的真实创伤当作营销素材；使用真实案例需获得许可并做匿名化处理。
- 不编造可核实的事实（奖项、数据、用户证言）。

## 切换到其他模型

- 用户其实在纠结真实人生选择 → `eternal-recurrence.md`（重大且不可逆）或 `stoic-control.md`（焦虑但不由己）。
- 要判断"这个新媒介会不会改变叙事形态" → `media-form.md`。
- 要做的是品牌的组织设计而非文案 → `semi-control.md` / `emergence.md`。

## 出处

约瑟夫·坎贝尔《千面英雄》（17 阶段）；克里斯托弗·沃格勒《作家之旅》（12 阶段实用缩编，源自坎贝尔）。
