# 媒介形式分析

**定位**：评估一种**新技术/新平台/新媒介形式**时，不问它"说了什么内容"，而问它**改变了什么**——人的感知比例、社会结构、以及"以前做不到而现在能做到"的事。

## 触发信号

- "AI（/VR/短视频/推荐算法）会带来什么影响？"
- "我们要不要 all in 这个新平台/新形态？"
- "为什么换了工具之后，团队的工作方式变了？"
- 需要做中长期的趋势判断而非短期内容评估

## 不该用它

- 分析**具体内容**好不好（一篇文章、一条视频、一个文案）→ 用内容/写作类方法。
- 评估**功能好坏或要不要做这个产品**→ 用产品/需求方法，本模型不评功能。
- 需要**时间点预测**（"哪年会取代 X"）→ 本模型不给时间表，别硬答。
- 短期决策、影响还不明显时。

## 核心判断

1. **媒介即讯息**：形式的改变比内容更能重塑人；同一内容换个形式，社会效果截然不同。
2. **媒介是人的延伸**：每种媒介放大某一种感官/能力，同时让另一种退化。
3. **媒介塑造人，多于人塑造媒介**：长期看结构与习惯被媒介改写；但这不是技术决定论——人的选择决定演化路径。
4. 判断要用**四定律**（Tetrad）四个问句，而不是"好/坏"评价。

## 操作步骤（媒介四定律）

1. **确认对象是形式而非内容**：要分析的是"短视频"这个形式，不是"某条短视频"。
2. **放大**：它放大了什么人的能力、感官或社会行为？（速度、范围、可见性、连接数）
3. **过时**：它让什么被边缘化或淘汰？（旧技能、旧中间环节、旧注意力模式）
4. **再现**：它把什么**已经消失的旧形式**重新唤回？（如：语音交互唤回口述传统、社群电商唤回熟人经济）
5. **逆转**：推到极致，它会反转成什么？（连接 → 过载；便利 → 依赖；可见 → 表演）
6. **落地判断**：列出"因为这个媒介，从前做不到、现在能做到"的 3 件事；判断其中哪些是机会、哪些是风险。
7. **标注不确定**：给出的是影响方向与机制，不是时间点与幅度。

## 输出模板

```
分析对象（形式）：……
放大：……
过时：……
再现：……
推到极致会逆转成：……
新增的可能性（3 条）：……
不确定的部分：……（无时间点预测）
```

## 判断标准

- 做对：能说清"形式如何改变了行为与结构"，判断在多年后仍站得住（方向对，时间不一定）。
- 做错：只在讨论内容与功能；把趋势说得像日程表。

## 误用模式

- **内容偷换**：把"某平台内容质量差"当成媒介分析结论。
- **决定论**：直接推出"技术必然导致 X"，抹掉制度与人的选择。
- **假精确**：给出"三年内取代 XX"式断言——超出本模型能力。
- **拿它替代产品决策**：媒介分析能说明影响面，不能说明"这个功能该不该做"。
- **反向滥用**：为了给既定投入找理由，用四定律拼凑正面叙事。

## 边界与安全

- 涉及成瘾性设计、未成年人、隐私与操纵性推荐时，必须点出伦理与合规风险，不提供"如何加大成瘾性"的操作建议。
- 不预测具体公司/产品的生死。

## 切换到其他模型

- 结论落到"这值不值得投入" → `first-principles.md`（算成本下限与真实约束）。
- 结论落到"要多方共存、自组织演化" → `emergence.md`。
- 结论落到"该管多严" → `semi-control.md`。
- 用户其实在问"我该不该转行进这个方向" → `cross-domain-transition.md`。
