# 认知架构：从现象到本质的跃迁路径

**定位**：当用户"感觉认知卡住了、努力了却没进展"时，用来**定位卡在四阶段里的哪一层**，并给出该层的破法。

## 触发信号

- "我努力了但没进展，像是撞到天花板"
- "别人能看到本质，我只能看到现象"
- "想系统性提升思维能力，而不是碎片化学习"
- 长期投入某方向，但仍看不到回报，怀疑方法

## 不该用它

- **只是看人物故事、听行业八卦**：这是资讯需求，不是方法需求。
- **已被裁员/被迫转岗、没有选择权**：先处理生存（`cross-domain-transition.md` 的"暂缓"部分）。
- **对目标领域一无所知**：先用学习方法类技能打地基。
- **已经在转型路上且进展顺利**：只需要情绪支持时用 `stoic-control.md`。
- **想快速拿具体操作技巧**：这是长期系统，不是速成法。

## 核心判断（只保留可判断的部分）

1. 认知升级不是"获取更多信息"，而是**重构处理信息的操作系统**。
2. 大多数人困在现象层（洞穴里的影子）；突破的路径是：怀疑 → 认识自己 → 保持饥饿 → 找到第二曲线。
3. **"五无阶段"（无回报/无反馈/无掌声/无价值/无同行者）是必经之路**，但它是**有期限的积累期假设**，不是无限忍耐的理由（见误用模式）。
4. 增长曲线有分岔：**密率分布**（先慢后快，推荐）与**指数衰减**（起点光鲜后平庸，须避免）。

## 操作步骤（四阶段）

**第一阶段 · 普遍的怀疑（破）**
1. 列出你视为"理所当然"的 10 条常识。
2. 逐条问：隐含假设是什么？如果假设错了会怎样？
3. 主动寻找反例，挑战自己的信念体系。
4. 接受因此而来的孤独与压力。

**第二阶段 · 认识自己（立）**
5. 画人生象限（X 轴时间 / Y 轴空间），标注当前位置。
6. 判断自己是否处在"五无阶段"：若是，确认**它已经持续多久、有没有可观察的积累**。
7. 明确"往前走必须留下什么"（时间/作品/关系的投资方向）。

**第三阶段 · 保持饥饿愚蠢（续）**
8. 持续追问"为什么"与"如果……呢"。
9. 积累"点"——即使当下看起来无用。
10. 等某个事件让点连成线；期间避免自满与认知封闭。

**第四阶段 · 第二曲线（跃）**
11. 画出第一曲线，标出**失速点**。
12. 识别**认知封闭**：原有因果框架已无法支撑增长。
13. 找**单一要素十倍化**的支点——**这一步就是第一性原理，直接按 `first-principles.md` 执行，不要在本文件里重述**（原 `tyl-cognitive-arch` 与本技能 `musk-first-principles` 在此重叠，已去重）。
14. 桥接非连续性，进入新的增长曲线。

## 输出模板

```
卡在哪一层：怀疑 / 认识自己 / 保持饥饿 / 第二曲线
证据（用户原话或事实）：……
该层的动作（1–3 条）：……
五无阶段检查：已持续……，可观察积累是……
失速点与认知封闭：……
若进入第四阶段 → 转 `first-principles.md`
```

## 判断标准

- 做对：能指出某个"常识"的隐含假设；在五无阶段仍有可观察的积累；找到一个可十倍化的要素；意识到还有更高维度。
- 做错：退回舒适区；停在指数衰减曲线；卡在失速点；把影子当真实。

## 误用模式

- **鸡汤化**：把四阶段讲成励志口号，没有可检验的动作与时间点。
- **用"五无阶段"合理化无限忍耐**：如果长期无回报、无反馈且看不到积累，应重新评估方向，而不是继续硬熬。
- **跳过第一阶段**：直接谈"十倍化"，产出的是口号不是路径。
- **把第二曲线当职业规划模板**：所有行业都要"找第二曲线"是话术，不构成判断。
- **对无选择权的人使用**：被迫转岗、被裁员者需要生存方案。

## 边界与安全

- 涉及个人成长叙事时属敏感信息：只处理用户主动给出的部分，不外发、不落盘。
- 不评价用户的能力高低或人格；不承诺"照做就能跃迁"。
- 情绪强度高、功能受损时转 `stoic-control.md` 的边界条款（建议专业支持）。

## 切换到其他模型

- 有明确目标领域、要换赛道 → `cross-domain-transition.md`。
- 第四阶段"单一要素十倍化" → `first-principles.md`。
- 焦虑来自不可控项 → `stoic-control.md`。
- 卡点其实是"信息过载、系统吸收不了" → `info-ecology.md`。
