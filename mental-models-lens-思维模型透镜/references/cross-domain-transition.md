# 跨领域转型

**定位**：想换行业/换赛道时，用来判断**该不该走**、以及走了之后**怎么把旧积累带过去**——转型不是放弃旧领域，而是带着思维武器换战场。

## 触发信号

- "我想从 X 转到 Y（传统行业转 AI、学术转工业界、换赛道）"
- "该不该离开现在的领域？"
- "我以前的积累会不会白费？怎么迁移？"
- 已在转型路上，卡在某一步不知道下一步做什么

## 不该用它

- **只是听人物故事、看行业资讯**：这是资讯需求，不是方法需求。
- **目标领域与旧领域毫无迁移点**（如纯重复劳动转需十年学术训练的方向）：五步法失效。
- **被裁员/被迫转岗、没有选择权**：先处理生存，再谈转型。
- **对目标领域一无所知**：先用地基类学习方法把基础打起来，再谈桥接。
- **已经很顺利只需要情绪支持**：用 `stoic-control.md`。
- **只是"感觉卡住、没进展"而没有目标领域** → `cognitive-arch.md`。

## 核心判断

1. 最可迁移的资产是**抽象能力**（数学、分析、方法论、工作流），不是具体工具技能。
2. "总想挑战自己不太会的事"与多年深耕不矛盾：深度积累 + 跨界勇气可以并存。
3. 转型是**边做边补**，不是先补后做——"等我准备好了"通常是拖延的借口。

## 操作步骤（转型五步法）

1. **能力盘点**：列出当前领域积累的可迁移能力，逐条问"它在目标领域值多少钱"——稀缺就带过去，通用就降级看待。
2. **桥接学习**：学目标领域的核心范式与工具；**自测标准**：能否快速读懂目标领域的一篇论文/一份技术文档。
3. **最小验证**：用一个小项目证明自己（不靠简历靠产出），让目标领域的同行认可。
4. **纵深切入**：用独特背景解决别人解决不了的问题——差异化切入点才是立足点，不要在入门技能上从零拼。
5. **持续跨界**：保持在舒适区边缘移动（换实验室、换公司、换项目），不把一次转型当终点。

## 输出模板

```
旧领域积累的可迁移能力：……（逐条标注"在目标领域是稀缺/通用"）
目标领域核心范式与工具：…… 桥接自测结果：能/不能读懂一篇论文
最小验证项目：……（产出物、验收人）
差异化切入点：……（我的背景能解决、别人解决不了的问题）
结论：可以走 / 暂缓 / 不适用——理由
```

## 判断标准

**可以离开的信号**：
- 领域内前沿问题对你不再构成智力挑战；
- 目标领域存在"你的背景能解决而常人不能"的问题集；
- 有足够的财务/心理缓冲期（学历已变现、积蓄到位）。

**暂缓离开的信号**：
- 只是厌倦，不是失去挑战；
- 目标领域没有差异化切入点，只能以纯入门水平竞争；
- 无缓冲期裸辞、断粮硬转。

## 误用模式

- **把五步法套在无迁移点的转型上**：硬推会让用户付出极高代价换来零起点竞争。
- **用"准备好了再走"拖延**：第 2 步给了自测标准，达标即应开始第 3 步。
- **把名字/头衔当迁移资产**："我是做 X 的"不是能力，技能清单才是。
- **忽略生存底线**：鼓励裸辞硬转是高风险建议；必须先确认缓冲期。
- **一次转型当终点**：把"入行"当成功，停止持续跨界。

## 边界与安全

- 收入、财务、家庭状况属高敏隐私：只处理用户主动给出的部分，不外发、不落盘。
- 不替用户做辞职/辍学等不可逆决定；只给判断框架与信号清单。
- 涉及心理健康（转型焦虑、身份危机）超出本模型时，转 `stoic-control.md` 或建议专业支持。

## 切换到其他模型

- 焦虑来自不可控项 → `stoic-control.md`。
- 决策不可逆且触及人生意义（是否值得）→ `eternal-recurrence.md`。
- 没有明确目标领域、只是感觉卡住 → `cognitive-arch.md`。
- 转型方向押注新技术 → 先 `media-form.md`，再算投入下限 `first-principles.md`。
