# 尼采永恒轮回测试

**定位**：面对**人生重大且不可逆的选择**或意义危机时，用一个思想实验检验："如果这段人生要无限次重复，我还会这样选吗？"——它检验的不是哪个选项正确，而是**你有多真诚**。

> 本模型是原思维模型族里流程最完整、禁忌最清楚的一个，作为本技能的**质量基准**：其余模型都应达到同样的"明确步骤 + 明确不适用人群"标准。

## 触发信号

- 纠结重大不可逆选择：换工作、分手/结婚、搬家、创业、生育
- "我的人生有什么意义""我做这些到底为了什么"
- 价值观冲突，不知道哪个选择"对"
- 对现有生活感到空虚、麻木、怀疑

## 不该用它（硬禁忌，命中任一即停用）

- **创伤后应激障碍（PTSD）**：对创伤者说"你要热爱命运"是二次伤害。
- **结构性不公**：贫困、歧视、剥削等系统性问题需要**行动改变**，不是"热爱"。
- **急性危机**：亲人去世、重病、重大变故期间，不做哲学测试。
- **只想了解尼采哲学史**：引导去读原著，不用本模型。
- **已经决定要做、只问怎么做**：那是执行问题。
- **只想被听见或需要现实支持**：先共情、先解决生存问题。
- **需要多视角互不妥协的攻防分析** → 用 `skill` 加载 `life-choice-roundtable`。

## 核心判断

1. 永恒轮回不是物理理论，是**生命态度的试金石**：愿意无限重复 → 肯定生命；逃避 → 虚无主义倾向。
2. 它不回答"哪个选择对"，只暴露"你是否在违背自己的深层价值"。
3. Amor Fati 不是被动接受，是主动拥抱发生的一切（包括苦难）——**前提是当事人有承受力且处境允许**。

## 操作步骤（五步）

**第一步：讲清测试。** 向用户说明思想实验，让他自己想象，不急着要答案：
> "假设你的人生会无限次重复，每一刻、每个细节都完全一样地重演——你会怎么想？"

**第二步：观察第一反应。** 问："如果这个念头出现，你的第一反应是什么？"
- 绝望型（"太可怕了，我无法接受"）→ 他在逃避生命的某些部分
- 狂喜型（"这正是我想要的"）→ 他在肯定生命
只需如实呈现，**不评判对错**。

**第三步：应用到具体选择。** 问："如果这个选择会被永远重复，你还会选吗？"
- "会" → 这个选择与你的深层价值一致
- "不确定" → 需要更深入地看
- "不会" → 这个选择可能违背了你的深层价值

**第四步：培养 Amor Fati。** 引导思考三个问题：
- 现在的生活里，哪些时刻你愿意永远重复？
- 哪些时刻你想逃避？
- 要让现在的生活"值得永远重复"，你需要改变什么？

**第五步：给出行动方向。**
- 否定结果 → 识别哪些选择违背深层价值，讨论如何调整（不是立刻推翻一切）
- 肯定结果 → 肯定选择，鼓励继续深化
- 不确定 → 建议记录一周"永恒轮回日志"：每天记下愿意/不愿意重复的时刻，找出模式

## 输出模板

```
第一反应：绝望型 / 狂喜型（原话引用）
应用到当前选择：会 / 不确定 / 不会
愿意永远重复的时刻：……
想逃避的时刻：……
结论（一句话）：这个选择与你的深层价值 一致 / 存在冲突，冲突点是……
行动方向 + 观察指标：……
边界提示：本测试不适用于【创伤/急性危机/结构性不公】情境
```

## 判断标准

- 做对：用户开始用"我愿意永远重复这个吗"检验选择；从"哪个对"转向"我有多真诚"；开始关注当下而非只盯未来目标。
- 做错：用户把它当成找"正确答案"的工具；用它逃避决策（"我测不出来所以先不动"）；把结果当终极判决，停止思考。

## 误用模式

- **当成决策机器**：期待它给出"该不该分手"的答案——它只反映真诚度。
- **用来回避**：用"我还没想清楚"无限期拖延。
- **对无权者使用**：对被迫转岗、被裁员、无选择权的人做哲学测试 = 残忍；先处理生存。
- **用它否定痛苦**：把用户的苦难解释成"你还没学会热爱命运"。
- **一次性的判决**：真实人生会变化，测试结果需要随时间复查。

## 边界与安全

- 人生抉择与意义危机内容属**高敏隐私**：只处理用户主动给出的信息，不外发、不落盘、不转述。
- **不是心理治疗**：出现自伤念头、持续两周以上的功能受损、急性创伤 → 立即停止模型化，给支持性回应并建议专业帮助。
- 不诊断、不贴"虚无主义者"标签；不把哲学结论强加给用户。

## 切换到其他模型

- 焦虑源于不可控项而非价值冲突 → `stoic-control.md`。
- 需要多视角攻防（四位大师互不妥协）→ `skill` 加载 `life-choice-roundtable`。
- 选择涉及具体换赛道操作 → `cross-domain-transition.md`。
- 感觉"卡住、没进展"而非"值不值得" → `cognitive-arch.md`。
