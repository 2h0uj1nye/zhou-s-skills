# 资源筛选与路径设计指南

## 资源筛选原则

### 数量原则：5 个资源
- 太少（1-2 个）→ 视角单一，容易遗漏重要角度
- 太多（6+ 个）→ 选择困难，无法聚焦
- **5 个正好**：覆盖不同角色，形成互补

### 角色搭配：5 种角色

| 角色 | 作用 | 典型类型 |
|------|------|----------|
| 主线教材 | 系统推进知识体系 | 官方教程、经典教材 |
| 视频课程 | 提供直观讲解和节奏感 | 大学公开课、系列视频 |
| 实战项目 | 通过做真实任务巩固知识 | 项目驱动型书籍/教程 |
| 刻意练习 | 大量小题训练肌肉记忆 | 在线练习平台 |
| 专题深挖 | 针对薄弱点定向突破 | 博客文章、专题文档 |

### 每个资源必须回答 5 个问题

1. **适合谁？** — 新手/有基础/想进阶
2. **难度如何？** — 入门/中级/高级
3. **该怎么用？** — 主线/补充/实战/练习/专题
4. **重点看哪里？** — 标注最值得投入的章节
5. **不要看哪里？** — 标注可跳过的冗余/过时/偏门内容

## 天级路径设计原则

### 每天结构：学 → 练 → 盘

```
学（输入）：40-60 分钟
  从主线教材/视频课程中学习当天主题

练（输出）：60-90 分钟
  做对应练习题，或在实战项目中完成当天任务

盘（复盘）：15-30 分钟
  回顾当天学的概念，自问"如果给别人讲，我能讲清吗？"
```

### 路径节奏

- **前 2 天**：打基础，聚焦最核心的概念
- **中间 3 天**：进阶 + 实战，开始做项目
- **最后 2 天**：综合 + 复盘，查漏补缺

### 任务颗粒度

- ❌ 错误：「今天学函数」
- ✅ 正确：「今天看官方教程第 4.6 节，做 Exercism 3 道函数相关题」

## 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 资源太多 | 选择困难，学不完 | 只选 5 个，其他收藏备用 |
| 路径太宽泛 | 不知道每天该干什么 | 每天任务精确到章节和题号 |
| 只看不练 | 学完就忘 | 学 1 小时至少练 1 小时 |
| 跳过复盘 | 不知道自己哪里不懂 | 每天留出 15 分钟复盘时间 |
