# 架构式快速突围详解（Track B）

## 角色定位

AI 是「高强度的辩论对手」，不是「省力的抄写员」。
任务不是帮你总结知识点，而是帮你**构建认知地图**和**探测理解盲区**。

## 三条铁律

| 铁律 | 说明 | 违反后果 |
|------|------|----------|
| 1.「48小时」仅限预习/复习 | 适合考前串讲或课题调研，**不用于**纯零基础硬核专业课的首轮学习 | 零基础直接用 → 知识架构空中楼阁 |
| 2. 必须保留「闭卷作答」环节 | Phase 3 的测试必须真写，写不出来就是真漏洞 | 跳过闭卷 → 自以为懂了 |
| 3. 强制 AI「自证」 | Phase 4 的防幻觉安全阀必须执行 | 跳过自证 → AI 幻觉被当成知识植入 |

## Phase 1: 抓取底层骨架（共识层）

### 执行提示词

> 请提炼出本学科领域内，所有顶尖专家普遍认同的 5 个核心思维模型或第一性原理。要求：用最通俗的比喻解释每个模型，并说明它如何串联起其他知识点。禁止罗列零散公式或事实。

### 输出要求

| 要素 | 说明 | 禁止 |
|------|------|------|
| 数量 | 精确 5 个，不多不少 | 不要「等」凑数 |
| 表达 | 每个模型用一个日常比喻解释 | 不要直接甩术语定义 |
| 串联 | 说明该模型如何连接其他知识点 | 不要孤立罗列 |
| 事实 | 只提炼「思维模型/第一性原理」 | 不要罗列零散公式或事实 |

## Phase 2: 标注争议边界（分歧层）

### 执行提示词

> 请找出该领域目前争议最大的 3 个核心议题。针对每个议题，客观列出正反两方的核心论据。

### 输出要求

| 要素 | 说明 |
|------|------|
| 数量 | 精确 3 个争议议题 |
| 客观性 | 正反两方论据都列出，AI 不站队 |
| 论据质量 | 每方至少 2 条核心论据，附简要推理 |
| 标注 | 明确标注该议题是「定论」还是「讨论中」 |

## Phase 3: 压力测试与漏洞修补（检验层）

### 执行提示词

> 请生成 10 道综合应用题，专门考察「是否真正理解逻辑链条」而非死记硬背。我将闭卷作答。

### 题目设计原则

| 原则 | 说明 |
|------|------|
| 考逻辑而非记忆 | 题目必须需要推理，不能靠背诵直接答出 |
| 综合性 | 每道题至少跨 2 个 Phase 1 的核心模型 |
| 陷阱设计 | 故意设置 Phase 2 中争议议题的常见误解为干扰项 |
| 难度梯度 | 前 3 题基础，中间 4 题进阶，后 3 题高阶 |
| 闭卷强制 | 题目输出后，AI 不给任何提示，等待用户提交答案 |

## Phase 4: 溯源验证（防幻觉安全阀）

### 4.1 批改与逻辑断点追溯

**第一步**：逐题批改对错。

**第二步**：针对每道错题，追问并回答：
> 「我错在哪一环逻辑？请引用原文依据或页码。」

### 4.2 强制 AI 自证

> 请复核你 Phase 1 和 Phase 2 输出的所有结论，指出其中可能存在争议或幻觉的部分，并标注依据来源。

### 执行要求

| 要素 | 说明 |
|------|------|
| 逐条复核 | Phase 1 的 5 个模型 + Phase 2 的 3 个议题，逐一检查 |
| 标注来源 | 每条结论必须标注「依据来源」 |
| 主动暴露 | 如果 AI 无法溯源 → 必须声明「此结论可能为幻觉，请人工复核」 |
| 区分确定性 | 标注每条结论的确定性等级：高（共识）/ 中（主流但非共识）/ 低（可能幻觉） |
