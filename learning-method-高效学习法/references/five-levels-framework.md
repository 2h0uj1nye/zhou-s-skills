# 五等级框架详解

## 等级定义

| 等级 | 名称 | 描述 | 标志 |
|------|------|------|------|
| L1 | 完全新手 | 零基础，第一次接触 | 能跟着示例敲出代码 |
| L2 | 语法入门 | 掌握了基本语法和概念 | 能独立完成简单练习 |
| L3 | 熟练应用 | 能组合多个概念解决问题 | 能完成小型项目 |
| L4 | 深入理解 | 理解底层原理和设计模式 | 能优化和重构代码 |
| L5 | 独立项目 | 能从零设计和实现完整项目 | 能做出可交付的作品 |

## 每个等级的输出内容

### 1. 核心知识点清单（5-10 项）
- 该等级必须掌握的知识点
- 按优先级排序

### 2. 常见错误（5-8 个）
- 该等级学习者最容易犯的错误
- 附简要解释和修正方法

### 3. 实践任务（1-2 个）
- 该等级的标志性练习或项目
- 完成后能证明达到了该等级

### 4. 晋级标准（可量化、可验证）

## 晋级标准写法原则

### 好的标准（可量化、可验证）
- ✅「能独立写出带参数、返回值和默认值的函数，并解释作用域」
- ✅「能使用列表和字典完成数据处理和统计任务」
- ✅「能独立设计并完成一个包含文件读写、错误处理的完整项目」

### 不好的标准（模糊、不可验证）
- ❌「理解了函数」
- ❌「掌握了数据处理」
- ❌「能独立做项目」

## 等级之间的关键跃迁

| 从 → 到 | 关键跃迁 | 常见卡点 |
|---------|----------|----------|
| L1 → L2 | 从"跟着敲"到"独立写" | 离开示例就不会写 |
| L2 → L3 | 从"写单个概念"到"组合多个概念" | 不知道怎么把知识点串起来 |
| L3 → L4 | 从"能用"到"理解为什么" | 知其然不知其所以然 |
| L4 → L5 | 从"理解原理"到"独立设计" | 不知道如何从零开始规划项目 |

## 晋级检查清单

进入 L2 之前：
- [ ] 能不看示例独立写出变量、条件、循环的代码
- [ ] 能解释常见错误的原因
- [ ] 完成了至少 10 道练习题

进入 L3 之前：
- [ ] 能独立完成一个 50 行以内的小程序
- [ ] 能用列表和字典处理实际数据
- [ ] 能阅读并理解他人的简单代码

进入 L4 之前：
- [ ] 能解释核心概念背后的原理
- [ ] 能优化和重构已有的代码
- [ ] 能用函数和模块组织代码

进入 L5 之前：
- [ ] 能从零开始设计并完成一个完整项目
- [ ] 项目包含文件读写、错误处理、用户交互
- [ ] 项目可以被他人直接使用
