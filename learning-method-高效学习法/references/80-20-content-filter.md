# 80/20 内容筛选指南

## 核心原则

**帕累托法则在技能学习中的应用**：20% 的核心内容覆盖 80% 的使用场景。

## 筛选流程

### 第一步：画出技能全景图
- 列出该技能的所有主要模块/章节
- 标注每个模块在真实使用中的频率

### 第二步：识别高频模块
- 找出每天/每周都会用到的模块
- 标注为「必须学」

### 第三步：识别低频模块
- 高级用法、冷门功能、极少出现的场景
- 标注为「可以跳过」或「用到再查」

### 第四步：确认前置依赖
- 哪些模块是理解其他模块的前提？
- 前置模块即使低频也必须学

## 筛选决策树

```
这个知识点：
├─ 每天都会用到？→ 必须学
├─ 不理解就无法继续学后面的？→ 必须学（前置依赖）
├─ 占实际使用场景 80% 以上？→ 必须学
├─ 有现成工具/库可以替代？→ 可以跳过，用到再查
├─ 高级/冷门用法？→ 可以跳过，先不看
└─ 实际工作很少遇到？→ 可以跳过
```

## 常见陷阱

| 陷阱 | 表现 | 如何避免 |
|------|------|----------|
| 完美主义 | 想把所有东西都学会 | 先问"这个知识点我每天会用吗？" |
| 被吓住 | 看到太多内容不敢开始 | 只选 3-5 个核心模块，其他不管 |
| 忽视前置 | 跳过基础直接学高级 | 画出依赖关系图，确认前置依赖 |
| 资源过载 | 收藏了 10 个教程不知道看哪个 | 只选 1 个主线教材，其他辅助 |
