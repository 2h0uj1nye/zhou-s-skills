# 速查表制作指南

## 速查表的 6 大必备模块

| 模块 | 作用 | 篇幅 |
|------|------|------|
| 一句话定义 | 用 1 句话讲清「这是什么」 | 1 行 |
| 核心概念 | 最重要的概念/语法/方法 | 3-6 个卡片 |
| 真实例子 | 3-4 个可直接运行的示例 | 1-2 个卡片 |
| 常见错误 | 新手最容易踩的坑 | 1 个卡片 |
| 使用前检查清单 | 动手前快速过一遍 | 1 个卡片 |
| 5 个自测题 | 从易到难的快速检验 | 1 个卡片 |

## 设计规范

### 布局
- 三栏卡片式网格
- 适合 A4 打印

### 配色
| 颜色 | 用途 |
|------|------|
| 技术蓝 (#667eea) | 核心概念 |
| 示例橙 (#ff9800) | 真实例子 |
| 警告红 (#e53935) | 常见错误 |
| 通过绿 (#34a853) | 检查清单 |
| 测验紫 (#9c27b0) | 自测题 |

### 交互
- 自测题带「看答案」按钮
- 点击揭晓答案
- 打印时答案自动显示

## 制作流程

1. 回顾学习内容，提炼精华
2. 按 6 大模块组织内容
3. 每个模块控制在 3-6 条要点
4. 自测题从易到难排列
5. 打印检查：格式是否正常，内容是否完整

## 常见问题

| 问题 | 原因 | 修正 |
|------|------|------|
| 内容太多，放不下 | 没有做减法 | 只保留最核心的 3-6 条 |
| 例子太复杂 | 没有选简单例子 | 用最小可运行示例 |
| 自测题没有梯度 | 题目难度都一样 | 按 L1→L5 排序 |
| 打印后格式错乱 | 没有做打印优化 | 添加 @media print 样式 |
