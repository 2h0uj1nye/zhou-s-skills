# arXiv 论文检索（arxiv）

> 一句话：用一句关键词在 arXiv 这个免费论文网站上找论文，把标题、作者、摘要、PDF 链接整理成能读的清单；还能顺手查这篇被多少人引用、引用了谁。

| 项目 | 内容 |
|---|---|
| 宿主 | DSH（Ubuntu 24.04 实测可用，脚本已内置限流重试；实测能返回真实检索结果） |
| 外部依赖 | 零安装依赖（用系统自带 `curl` 或 `python3`），但**必须联网**；不需要 API key |
| 产出 | 论文清单、单篇元数据、BibTeX 引用条目、引用/被引列表、相关论文推荐 |
| 入选理由 | 免费、免注册、免装包，学术检索是高频刚需，脚本只用 Python 标准库 |

## 它解决什么问题

想找某个方向最近有什么论文，搜索引擎给的是一堆二手解读，原文还要再找一圈；Google Scholar 又动不动弹验证、界面重，也不好批量拿"标题 + 作者 + 摘要"来筛。
arXiv 有官方免费接口，但返回的是一坨 XML（一种给机器看的标记格式），人直接看很难受——这个技能就是替你把那坨 XML 变成人话。

## 什么时候该用它

- "帮我找 GRPO 强化学习最近的论文，要最新的十篇。"
- "查一下 Yann LeCun 最近发了什么。"
- "cs.AI 这个方向最近有什么新东西？"
- "这篇 2402.03300 被引用了多少次？"
- "给我这篇的 BibTeX，我要写进参考文献。"

## 什么时候别用它

- 你要找的论文不在 arXiv 上（期刊、会议、专利、中文文献基本都不在，arXiv 主要收预印本）。
- 你要精读全文 PDF——技能给的是 PDF 链接和读取方式，本地 PDF 解析是另一个技能（`ocr-and-documents`）的事。
- 你想一次扒几千篇做数据集——arXiv 限速约 3 秒一个请求，大量抓取会被掐。
- 你已经有论文链接、只想知道它讲了什么——直接读那个链接就行，不用过这个技能。

## 怎么开口

- "帮我搜 'retrieval augmented generation' 最近 10 篇，按时间排。"
- "用 arxiv 查一下 2402.03300 这篇的引用数。"
- "找 transformer 相关的，只要标题里有的。"
- "给我这篇生成一份 BibTeX。"

## 输入 / 输出

**它会向你要：** 关键词，或作者名，或分类（如 `cs.AI`），或论文编号（如 `2402.03300`）；排序和条数可选。

**最后给你：** 每条含论文编号、标题、作者列表、发布日期、分类、摘要前 300 字、摘要页与 PDF 链接的清单；查单篇时给完整元数据；另外还能给 BibTeX 条目（可直接贴进参考文献）、引用它的论文、它引用的论文、相关推荐、作者 h-index 等。

## 依赖与前提

系统自带 `python3`（本机为 Python 3.12）和 `curl`——脚本只 import `sys` / `urllib` / `xml.etree`，**不用 pip 装任何东西**。
需要能访问 `export.arxiv.org`（论文接口）和 `api.semanticscholar.org`（引用数据）。不需要 API key。

## 注意事项与已知限制

- **arXiv 会临时限流（已缓解，未根除）。** 密集请求时 arXiv 返回 `406 Not Acceptable`，而同一个 URL 用 `curl` 往往是 200——说明是限流不是网络不通，限流窗口通常一两分钟内自行恢复。
  - 已做的修复：脚本内置 **5 次退避重试**（3/6/12/24 秒 + 随机抖动），并把失败时的 traceback 换成可读提示（说明大概率是限流、建议等待后重试），退出码非零。
  - 仍可能遇到：限流窗口超过约 1 分钟时，5 次重试会耗尽并报失败。此时**等 1-2 分钟再跑一次**即可，不要连续猛试（那只会延长限流）。
- **命令示例已统一为 `python3`**：原来的「完整研究工作流」第 1 步和脚本注释里写的是 `python`（Ubuntu 上没有这个命令），现已全部改为 `python3`。
- **网络抓取写法已适配宿主**：原文用 `web_fetch(urls=[...])`（列表形式，是另一个宿主的写法），本宿主的 `web_fetch` 只接单个 `url`，照抄会失败；6 处已全部改为 `web_fetch(url="...")`。
- **`web_fetch` 的写法是别的宿主的**：正文写的是 `web_fetch(urls=["…"])` 这种列表形式，而 DSH 的 `web_fetch` 只接受一个 `url` 参数，照抄要改成单个参数。
- 限速要当真：arXiv 约 1 请求 / 3 秒，Semantic Scholar 无 key 时 1 请求 / 秒（有 key 可到 100/秒）。
- 编号版本号要注意：不带 `v` 的链接永远指向**最新版**，带 `v1` 的是固定版本，引用时最好保留你实际读的那一版。
- 撤稿论文不会消失，摘要里会带 "withdrawn" 字样，得自己看。
